Native TV interface

AFT Home ↗

A lightweight Android TV launcher for Fire TV, with a clear app layout and navigation designed for a remote.

  • Java
  • Android TV
  • Gradle
GitHub ↗README ↗
A closer look

Interface. Installed apps are discovered and ordered into a horizontal row. D-pad navigation remembers the last focused app.

Device behavior. A launcher chooser, Wi-Fi shortcut, and low-motion screensaver are documented alongside the Fire OS setup and recovery steps.

Work proof. The repository includes the native Java implementation, build instructions, and screenshots captured on Fire TV.

Everyday automation

Newsbot ↗

A personal AI and technology news digest that collects RSS headlines and links, then delivers them to Telegram.

  • Python
  • RSS
  • GitHub Actions
GitHub ↗README ↗
A closer look

Workflow. Configured RSS feeds are fetched, filtered by a lookback window, and formatted into a headlines-and-links digest.

Running it. The command line supports feed checks and dry runs. GitHub Actions can run the digest on a daily schedule.

Work proof. The public source separates feed handling, configuration, digest formatting, and Telegram delivery, with offline tests documented in the README.
